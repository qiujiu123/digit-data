# 单篇论文页与网页卡片字段

本参考适用于新建或维护本地文献 Wiki。保留项目已有字段命名；只有在生成器能稳定读取时才新增字段。

## 单篇 Markdown 建议字段

```markdown
# 题名

> 🧭 论文页面 NN / 总数；概述据所列源文件整理。

## 书目信息
- 年份：正式发表年份；未正式发表时注明预印本年份
- 会议 / 期刊 / 材料类型：正式 venue 或材料状态
- DOI / 稳定链接：出版方 / DOI / 预印本页面
- 源 PDF：相对路径
- 版本说明：本地文件与正式出版版本是否一致

## 摘要概述
🧭 任务背景、研究问题和具体困难。

## 方法概述
🧭 输入与输出、处理步骤、关键模块及其作用。

## 主要结论
🧭 作者报告的效果、使用的证据，以及结论适用范围。

## Wiki分析的待解决问题
🧭 由已知局限、实验范围或跨论文比较提出；不要冒充作者原文。

## 主题标签
#领域 #问题 #方法

## 相关论文
[NNN](./NNN.md)：说明共同方法、可比较问题或互补关系。

## 核对记录
- 🧭 题名 / 方法 / 结论依据：源 PDF 的摘要、正文或结论部分。
- 🧭 venue 核对依据：正式出版方、论文集、期刊或 DOI 页面。
```

方法、问题和证据字段应写成有具体信息的短段落，不以“效果更好”“表现优异”等无出处评价替代实验事实。未从 PDF 或可靠来源确认的数字、页码、版本状态不应补写。

## 网页卡片映射

单篇 Markdown 生成以下卡片区块：

| 卡片区块 | 内容来源 | 说明 |
|---|---|---|
| 论文模型图 / 流程图 | PDF 图或 Wiki 示意 | 两类图必须明确标注，不可互换 |
| 研究问题与具体难点 | 摘要概述 | 说明为什么需要该研究 |
| 方法流程与关键模块 | 方法概述 | 按输入、处理、输出描述模块关系 |
| 论文效果与证据边界 | 主要结论 | 区分作者报告和 Wiki 分析 |
| 待解决问题 | Wiki分析的待解决问题 | 标注为 Wiki 判断，并尽可能逐篇定制 |
| 相关论文 | 相关论文 ID 与方法 / 主题标签 | 为每条关联说明依据和差异 |
| 发表信息 | 书目信息 | 显示年份与期刊 / 会议或材料状态 |

## 更新原则

- Markdown 页面是人工维护的源数据，网页 JS 是生成物。编辑源页后运行项目生成脚本；不要只改生成出来的 JS。
- 引用关系只代表论文原文有可查引文或作者关系时才这样标记。按方法或主题归纳的边写成“相关路线 / 共同问题”等描述。
- 对正式发表版和本地预印本不一致的项目，同时记录两者，不覆盖原 PDF，也不把文件版本说成出版版本。
- 新增条目时检查索引排序、方法分组成员、图像 manifest、相对链接和总数；删除或跳过 PDF 时记录原因。
